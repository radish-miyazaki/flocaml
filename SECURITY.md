# Security Policy

flocaml reads Nix expressions that may come from untrusted sources. A crash, a hang or an excessive use of memory on some input counts as a security issue.

## Reporting a Vulnerability

Please report vulnerabilities privately through [GitHub's security advisories](https://github.com/radish-miyazaki/flocaml/security/advisories/new) rather than in a public issue, with the input that triggers the problem if you can.

You should receive an answer within a week.

## Supported Versions

Only the latest release receives fixes.
